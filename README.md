# AI Haiku Noise

A no-dependency browser toy that turns any sentence into a three-line absurd haiku. The generator is deterministic for the same input, so a friend can compare a shared "seed" without a server.

## Run

Open `index.html` in any modern browser. No build step, network request, or API key is required.

## Controls

- Type or paste up to 240 characters.
- Select a sample prompt or press **Generate noise**.
- Use **Copy haiku** to place the three generated lines on the clipboard.
